Name

Type

Description

symbol

char

The name of a financial instrument. The name can only contain Latin letters without punctuation, spaces or special characters (may contain ".", "_", "&" and "#"). The maximum length (including the end of line character) is 12 characters.

digits

int

The number of decimal places in the symbol quotes.

count

int

The position of a symbol. It is a parameter for internal use.

visible

int

A non-zero value - the symbol is selected in Market Watch, 0 - not selected. To add a symbol to Market Watch, use CManagerInterface::SymbolAdd.

type

int

The index of a group of symbols, to which this symbol belongs, in the ConGroup::secgroups array.

point

double

Point value. It is calculated as 1/(10^digits). It is a service parameter.

spread

int

Symbol spread. If you set a value other than "0" in this parameter, the spread will be considered fixed and will be calculated for the symbol using the spread_balance option: The 0 value means that the spread is floating.

spread_balance

int

Spread balance. The value of the spread balance is defined as an offset from the equal division of the spread value (ConSymbol::spread) between the Bid and Ask prices. For example, if the spread is 10, its distribution in the ratio of -5 Bid/+ 5 Ask is equal to the spread balance value of 0. Ratio -6 Bid/+4 Ask corresponds to -1, ratio -4 Bid/+6 Ask corresponds to 1. If the spread value is odd, the 0 value of the spread value corresponds to its even distribution between the Bid and Ask prices with an offset of 1 in the Ask direction. For example, if the spread is 3, the zero spread balance corresponds to the ratio -1 Bid/+2 Ask.

 

Three scenarios of price spreading are possible:

 

  • If the spread of received quotes is equal to the spread set for the symbol, the difference between the prices is reduced by the formula: New Bid = Bid + Points * Spread Balance, where Points is the point value (ConSymbol::point). New Ask = New Bid + Spread.
  • If the spread of received quotes differs from the spread set for the symbol, the difference between the prices is set by the formula: New Bid = (Ask + Bid)/2 - Points * (Spread/2 - Spread Balance), where Points is the point value (ConSymbol::point). New Ask = New Bid + Spread.
  • If floating spread (0) is set for the symbol, prices are shifted by the same Spread Balance value.

direction

int

Price change direction relative to its previous state. The field is outdated and is not used.

updateflag

int

A flag indicating that the prices have changed. A nonzero value means changes, 0 - no changes.

lasttime

__time32_t

The time when the last tick for the symbol was received. The date is specified in seconds since January 1, 1970.

bid,ask

double

The last Bid and Ask prices.

high,low

double

The last High and Low prices.

commission

double

Commission amount. The units of commission depend on comm_type.

comm_type

int

The units, in which the commission amount is specified. It is a value from the enumeration Commission units.
